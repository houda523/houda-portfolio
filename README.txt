PORTFOLIO DE HOUDA BAKRI — VERSION 2 (FR / EN)

LANCEMENT
1. Décompressez le ZIP.
2. Ouvrez le dossier portfolio_houda_bakri_v2.
3. Double-cliquez sur index.html.
Aucun serveur ou installation n’est nécessaire. Une connexion internet est utile pour charger les polices Google, mais le site reste lisible sans elles.

FONCTIONNALITÉS
- Design moderne responsive pour ordinateur et mobile.
- Interface bilingue français / anglais.
- Photo de profil intégrée.
- CV PDF réel inclus dans assets/cv.pdf et boutons de téléchargement.
- Six projets avec fenêtres de détails.
- Section labs / pratique.
- Parcours et expériences en timeline.
- Certifications listées à partir des informations du CV.
- Compétences techniques par catégorie.
- Bouton mode sombre / clair avec préférence locale.
- Lien GitHub : https://github.com/houda523
- Formulaire de contact qui prépare un e-mail via l’application mail configurée (pas de serveur backend).
- Liens de navigation et animations au défilement.

À VÉRIFIER AVANT PUBLICATION
- Le lien LinkedIn est encore générique : remplacez https://www.linkedin.com/ par l’URL exacte du profil.
- Ajoutez des liens de dépôts spécifiques et des captures aux projets lorsque ces éléments sont publiables.
- Les statistiques GitHub renvoient au profil réel ; aucun nombre d’activité n’est inventé.
- Vérifiez que chaque description reflète précisément le travail réellement effectué.
- Ne publiez pas de rapports ou captures contenant des informations confidentielles d’entreprise.

FICHIERS
- index.html : contenu et structure
- style.css : style, responsive et thèmes
- script.js : interactions, langue, projets et thème
- assets/houda-photo.jpeg : photo de profil
- assets/cv.pdf : CV fourni
